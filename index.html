What is Declarative Programming?
● ~10 minutes

Everything you have programmed so far has been imperative: you tell the computer how to solve a problem, step by step. In declarative programming you tell it what is true, as a set of facts and rules. You then ask a question (a goal), and the language's inference engine works out the answer for you. The best-known declarative language is Prolog.

Imperative
# Imperative: HOW to find them for Animal in Animals: if Food[Animal] == "meat": print(Animal)
Declarative
// Declarative: WHAT is true carnivore(X) IF eats(X, meat). // Goal (question) carnivore(X)
TermMeaningExample
FactSomething that is unconditionally truetype(lion, mammal).
RuleSomething that is true if its conditions are truecarnivore(X) IF eats(X, meat).
Knowledge baseThe full set of facts and rules for a problemClauses 01 to 17 below
PredicateThe name of a fact or rule, describing a property or a relationshiptype, eats, carnivore
Goal (query)A question the inference engine tries to satisfy using the knowledge basecarnivore(X)
This page and the next: this pre-learning is about writing facts and rules from information you are given. Part 2 is about writing goals and working out how the inference engine satisfies them.
CIE 9618 Specification (20.1): understanding of and ability to solve a problem by writing appropriate facts and rules based on supplied information.

Writing Facts
● ~20 minutes
Quick recap: A fact is written as a predicate followed by its arguments in brackets, and ends with a full stop. In exam questions each clause has a line number (01, 02…) so you can refer to it; the numbers are not part of the code.
The scenario used in Sections 2 to 4
A wildlife park keeps a lion, a penguin, an eagle, a shark and a bat. Lions and bats are mammals, penguins and eagles are birds, and sharks are fish. Lions and eagles eat meat, penguins and sharks eat fish, and bats eat insects. Eagles and bats can fly.
The wildlife park knowledge base
01 animal(lion). 02 animal(penguin). 03 animal(eagle). 04 animal(shark). 05 animal(bat). 06 type(lion, mammal). 07 type(penguin, bird). 08 type(eagle, bird). 09 type(shark, fish). 10 type(bat, mammal). 11 eats(lion, meat). 12 eats(penguin, fish). 13 eats(eagle, meat). 14 eats(shark, fish). 15 eats(bat, insects). 16 canfly(eagle). 17 canfly(bat).
Rule for writing factsExample
Predicate name in lower caseeats
Arguments in brackets, separated by commas(lion, meat)
Constants (actual things) in lower caselion, meat
End with a full stopeats(lion, meat).
Keep the argument order the same every timealways eats(Animal, Food)
Only write what is true: there is no fact saying a lion cannot fly. Anything not in the knowledge base is treated as false, so you never need "negative" facts.

3
Writing Rules with IF
● ~20 minutes
Quick recap: A rule says something is true if certain conditions are true. It has a head (the conclusion) before IF and a body (the conditions) after it. Rules use variables, which start with a capital letter and stand for "any value that makes this work".
A rule
carnivore(X) IF eats(X, meat).
Read it in English

"X is a carnivore if X eats meat." X is a variable, so the rule works for any animal. Using the knowledge base, the lion and the eagle are carnivores.

Why use a rule?

One rule replaces many facts. Add a new meat-eating animal and it automatically becomes a carnivore, without writing a new carnivore fact.

PartIn carnivore(X) IF eats(X, meat).
Head (conclusion)carnivore(X)
Body (condition)eats(X, meat)
VariableX (capital letter); Animal would work just as well
Constantmeat (lower case: one specific value)
Same name, same value: within one rule, every X stands for the same thing. In carnivore(X) IF eats(X, meat). the X that is a carnivore must be the X that eats meat.
✎ Worked exam-style question
Write a rule to show that an animal is a fisheater if it eats fish. [2]
Think of your answer first, then reveal the mark scheme.
Mark scheme — one mark for each point:
  • Correct head: fisheater(X)

Examiner tip: Use a capital letter for the variable and lower case for fish, which is a constant.

4
Rules with AND, NOT and OR
● ~20 minutes
Quick recap: A rule's body can have more than one condition. AND means every condition must be true for the same values of the variables. NOT means the condition must not be found in the knowledge base. Two rules with the same head work like OR: the head is true if either rule succeeds.
Rules with AND, NOT and OR (added to the wildlife park)
18 flyingmammal(X) IF type(X, mammal) AND canfly(X). 19 flightlessbird(X) IF type(X, bird) AND NOT canfly(X). 20 dangerous(X) IF eats(X, meat). 21 dangerous(X) IF type(X, fish).
RuleIn EnglishAnimals that satisfy it
flyingmammalX is a mammal and X can flybat
flightlessbirdX is a bird and X cannot flypenguin (the eagle can fly)
dangerousX eats meat or X is a fishlion, eagle, shark
Linking two things with a shared variable: variables can connect conditions. samefood(X, Y) IF eats(X, F) AND eats(Y, F). means "X and Y eat the same food F". The two F's must be the same value.

✓ Summary — CIE 9618 Topic 20.1: Declarative Programming (Part 1)
Declarative programming: you state what is true as facts and rules; the inference engine works out how to answer a goal.
Facts: always true. Lower-case predicate and constants, arguments in brackets, full stop: type(lion, mammal).
Argument order: decide what each argument means and use the same order every time. Anything not stated is treated as false.
Rules: head IF body. True only when the conditions are true: carnivore(X) IF eats(X, meat).
Variables: start with a capital letter. The same variable in one rule stands for the same value, which lets conditions share information.
AND, NOT, OR: AND joins conditions, NOT succeeds when a condition is not found, and two clauses with the same head act as OR.
